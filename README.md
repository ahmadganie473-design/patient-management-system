

Patient Management System

A Java-based Patient Management System demonstrating object-oriented programming principles and CRUD functionality.

 Features
- Add patient records
- Search for patients
- Update patient information
- Remove patient records
- Input validation for user entries

 Technologies Used
- Java
- Eclipse IDE

 Object-Oriented Programming Concepts
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation

## Project Structure
- `Person.java` - Parent class containing shared information
- `Patient.java` - Represents patient information
- `Doctor.java` - Represents doctor information
- `Main.java` - Runs the application and handles user interaction

## Concepts Demonstrated
This project applies CRUD operations (Create, Read, Update, Delete), object-oriented programming, ArrayLists, loops, conditional statements, and input validation.
